# 轻声 · 本地朗读

当前版本：1.7.4-ios.1。新增点读模式、只读角色对白开关和 iOS 缓存交接。缓存上限改为 500 MiB，台词与心理活动按完整气泡朗读，旁白保留逐句。新增 iOS 配套 App 原生播放器接口；普通浏览器保留 Web Audio 路径。新增可配置接口地址、密钥与 Docker 局域网接口。在扩展设置和轻声面板加入「启动轻声」，保留正文快捷朗读、中文音色、多角色配音与 PCM 流式播放。

## 两台电脑同步

仓库：<https://github.com/bycgxd/breeze-reader>（公开）。首次安装、更新与提交方法见 [GitHub同步说明.md](GitHub同步说明.md)。仓库只同步插件代码；音色、模型、连接密钥及角色配音设置留在各自设备。

## 日常使用

1. Windows 模型电脑先打开 Docker Desktop 和酒馆，再双击「启动手机连接.bat」启动模型及手机接口。手机和 Mac 使用 `http://192.168.31.178:8790` 并填写连接密钥；面板的「启动轻声」在远程连接时只检查服务，不能启动 Windows。仅本机使用时可运行「启动轻声.bat」，本机接口为 `http://127.0.0.1:8789`。
2. 点消息的“朗读清单”，只识别已经渲染的对白、旁白/动作和心理活动。不会读取隐藏原文；状态栏和时间地点不读。
3. “多角色朗读设置”默认展开。选择“多角色配音”，给旁白、人物、心理活动分别选声音；也可选择“统一音色”，全部使用默认声音。
4. 已识别人物会自动列出。可以在“添加自定义人物”输入人物名，提前绑定音色；名字需与正文识别结果一致。当前消息未出现的已保存人物也会保留在设置里。
5. 每次选择自动保存到当前角色卡的轻声配音方案，不写角色卡文件。同名不同卡片分别保存。切换统一/多角色模式不会清空绑定。
6. 心理活动默认跟随人物，也可指定统一的心理活动声音。未绑定人物跟随默认声音；“清除绑定”让该人物恢复默认。
7. 点“本句”只读一句；“从这里继续”或消息“朗读”按正文顺序读下去。支持暂停、继续、停止、上一句、下一句和失败重试，原正文按实际播放位置高亮。

## 直接在正文操作

- 选中文字后，约 100 ms 出现轻声浮条。点“朗读选中内容”只读实际选中的字符，跨人物时分别用对应音色，不读姓名标签、代码或隐藏源。只支持同一条消息、同一文档内的选区。
- 浮条的“从此句继续”从选区起始所在句的句首读到本消息末尾。选区播放的上一句、下一句和重试则保留在选区内，不扩展为全文。
- 按住 Alt 点击正文某句，从该句继续朗读。普通点击默认不触发声音，链接、按钮和输入框继续保持原操作。
- 正文右键出现“读这一句”“从此句继续”“停止朗读”。在正文按 Shift + 右键可保留浏览器原菜单；正文之外或链接上的原菜单不接管。这是轻声页面浮条，不是额外安装的浏览器右键扩展。
- 需要直接点哪句读哪句时，在面板开启“单击正文读本句”，默认关闭。单击会短暂等待以区分双击；拖选与双击选字不会抢先朗读。
- Escape、点击别处或滚动会关闭浮条。右键浮条可用方向键移动按钮焦点。面板可关闭“启用正文快捷朗读”，原有播放按钮仍可用。
- 同源正文 iframe 内同样可选字和右键；交互组件 iframe、不可访问的跨域 iframe、用户消息及状态栏不纳入。iframe 重载后重新绑定，旧浮条被清除；即使文字相同，也不会沿用旧文档的音频与高亮。

所有操作只读取已经渲染的正文及原有句子 Range，不重新包装正文或改写气泡脚本。临时浮条、样式和监听在停用后清除。

## 流式与缓存

只有 PCM 流式路径，没有旧分段模式开关和酒馆完整 WAV 转发路径。模型边生成，轻声边接收并使用同一 AudioContext 时间轴播放。约积累 1.2 秒音频后起播，最多提前安排约 8 秒；短内容接收完即可播放。模型持续慢于播放时仍可能需要缓冲。

播放速度可调。播放中修改会停止当前任务，重新播放时使用新速度。可选跟随滚动默认关闭，手动滚动会暂停跟随。

音频缓存默认开启，使用当前浏览器 IndexedDB，按账号的轻声配置标识隔离，上限 500 MiB，超限淘汰较久未用的缓存。成功接收完整片段才保存，播放倍速、人物名称或中文备注变化不使相同音色与文本的音频失效。存储不可用时提示并使用有上限的页面内存缓存。

“预生成本条”顺序准备当前消息音频，不播放，可取消。新回复处理支持手动、仅预生成、自动播放；只处理本次新完成且稳定渲染的正文，不自动读历史记录。停止、编辑、切换聊天或停用会取消旧任务。

缓存面板可查看用量，清理当前聊天或当前账号全部轻声缓存。共享音频在其他聊天仍被引用时保留。没有音频下载功能。

## 音色与启动

音色目录：D:\BASE\桌面\work\素材库\音色。

插件显示目录里的原文件名，支持中文、空格等名称。纯改名后点“刷新本地音色”即可，声音内容不变时人物绑定保持不变。新增音色或替换声音内容后点击「启动轻声」或重新运行启动轻声.bat，它会自动准备兼容副本，检查模型是否已加载，并在必要时重载模型；随后刷新插件。WAV/MP3 参考录音需先由模型保存为 .breeze，不会直接作为已注册音色。

当前 Windows 模型对中文音色 ID 有乱码问题，轻声在自己的运行缓存中生成兼容副本，内部编号与显示名称分离；原目录的文件不改名、不移动、不覆盖。原有英文配音通过文件修订信息与内容对应继承，不要求重新绑定。

轻声本机接口只监听 127.0.0.1:8789，固定连接 127.0.0.1:8080 模型并读取指定音色目录。只允许已有酒馆页面来源，合成请求使用每次启动的随机令牌。使用现有 Python 3.12，无新增包依赖。启动器不自动启动 Docker 或酒馆容器。它在当前用户的 HKCU\Software\Classes\breeze-reader 注册专用网址入口，只运行本插件的固定启动脚本，不接收网址中的命令参数；不会设置开机自启。

手机和其他电脑现在可以通过 Docker 接口访问 Windows 模型，详见「手机与Docker连接.md」。单机接口仍保留；没有保留旧分段模式回退。

## 隔离与限制

不修改气泡脚本、正则、角色卡、世界书、酒馆源码或其他扩展设置；不自动开关内置 TTS。停用后清除轻声控件、高亮、监听与观察器，原文字节点和 iframe 保持原样。后台模型和本机接口会继续运行供其他调用复用。

情绪标签仅显示，尚未启用真实语气控制；不提供音色创建、上传或跨设备缓存同步。更换模型、参考音色后建议清理旧缓存。浏览器本地网络权限若阻止连接，需要允许访问本机接口。
